# Editable reader

Svelte 5 runes, Vite 8, ordinary JavaScript with JSDoc checking. No SvelteKit, Tailwind, database, provider SDK, or model runtime. The live source is the normal playing mode; `npm run build` verifies optional distribution output.

Run `npm ci`, start the Python bridge as described in [setup](../docs/setup.md), then `npm run dev -- --host 127.0.0.1 --port 5173 --strictPort`. The allowed origin must match. Vite reads private connection details only on the server, proxies narrow public routes, and refuses arbitrary /@fs and private paths even if source accidentally imports them. Public portraits come from Python, not Vite's public folder.

App owns channel/snapshot/status composition. Conversation preserves scroll position, settles at entry boundaries, and starts long new passages from their top; ProseEntry sanitizes Markdown and reveals only new writer IDs. Composer owns current transport feedback; Session persists workspace/channel drafts, immutable uncertain requests, and reading anchors in same-tab session storage. API serializes polling with ETags and cancellation; it never polls a model or interprets fiction. CastPanel renders only disclosed records and unmodified portrait appearance, with an initial fallback if a portrait is loading or unavailable; narrow screens use an inert-backed dialog drawer with focus return. Public portrait bytes are path-resolved and PNG-structure validated by Python before hashing or serving. Initial history/revisions/recovery render immediately. Animation never grants or blocks saving.

Use `npm run check`, `npm run test:unit`, and `npm run build`; `python tests/run_browser.py` at the root manages temporary services for `npm run test:browser`. Playwright output lives in ignored test-results. Development screenshots are kept with the upstream development documentation. Actual stories remain empty until supplied. Do not run the browser tests against a real story workspace.

All direct packages use approved exact versions in package.json and package-lock.json. Source Serif 4 and Source Sans 3 files come from @fontsource 5.2.8 packages; accompanying OFL licenses are in fonts/. Fonts are bundled/self-hosted and require no runtime external stylesheet. Dependency audit observations are maintained with the upstream development documentation. Maintain the public contract and the installed UI/Svelte skill conventions when editing.
