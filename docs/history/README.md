# History

> **Not current instructions.** Everything in this folder is preserved history: how the design was reached, what was planned, and what happened along the way. It may describe superseded decisions, completed steps, or open questions that have since been settled. When anything here differs from the [design](../designs/couldhappen.md), [setup](../setup.md), [public contract](../public-contract.md), or [writer skill](../../.agents/skills/couldhappen/SKILL.md), those win. Agents searching the repository should not act on text found here.
